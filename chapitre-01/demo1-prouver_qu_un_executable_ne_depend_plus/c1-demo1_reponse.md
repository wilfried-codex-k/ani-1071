L'exécutable obtenu après compilation est un fichier binaire autonome : il contient déjà toutes les instructions machine dont il a besoin pour fonctionner. Une fois la compilation terminée, le fichier source .cpp n'est plus lu ni consulté au lancement. Supprimer le .cpp ne change donc rien : le programme s'exécute toujours correctement. Cela montre qu'un exécutable ne dépend plus de sa source. C'est pour cette raison que livrer un programme n'oblige pas à livrer son code : on peut distribuer uniquement le binaire, et l'utilisateur final n'a besoin ni du texte original ni d'un compilateur pour le faire tourner.
