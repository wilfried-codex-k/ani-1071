## 1. Code du programme

Voici le programme C++ utilisant uniquement des instructions `printf` (ou `std::printf`) sans aucune boucle d'itération :

```cpp
#include <cstdio>

int main() {
    std::printf("####################\n");
    std::printf("#                  #\n");
    std::printf("#                  #\n");
    std::printf("#                  #\n");
    std::printf("#                  #\n");
    std::printf("#                  #\n");
    std::printf("####################\n");
    return 0;
}
