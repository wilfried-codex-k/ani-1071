# Réponse

J'ai lu une année puis j'ai utilisé des conditions pour vérifier si elle est bissextile.

Une année est bissextile si elle est divisible par 4, sauf si elle est divisible par 100. Si elle est divisible par 400, elle est quand même bissextile.

J'ai testé avec `1900`, `2000`, `2024` et `2100`.

Les résultats sont :

* `1900` : non bissextile
* `2000` : bissextile
* `2024` : bissextile
* `2100` : non bissextile
