# Réponse

J'ai utilisé l'opérateur ternaire `? :` pour faire les quatre affichages sans utiliser de `if`.

Le premier ternaire permet de trouver le plus petit nombre.

Le deuxième permet de trouver le plus grand.

Le troisième permet de savoir si le premier nombre est pair ou impair.

Le dernier permet d'afficher « objet » si le nombre vaut `1`, sinon « objets ».

Les deux nombres sont lus une seule fois au début du programme.
